# Resultados e plots

Todos os plots, CSVs, vídeos e logs persistentes ficam nesta pasta.

## Pastas

- [`sl_runs/`](sl_runs/index.html): todos os resultados SL, organizados por experimento, veículo e modelo.
- [`rl_runs/`](rl_runs/index.html): ações, sinais, vídeos e TensorBoard de RL.
- [`dataset_diagnostics/`](dataset_diagnostics/README.md): diagnósticos de datasets e modelos.

Novos resultados SL são gravados em `sl_runs/generated/`. Novos resultados de RL vão automaticamente para a subpasta correta em `rl_runs/`.

Os comandos principais estão no [README do projeto](../README.md) e no [README de RL](../rl/README.md).
